# NVIDIA DLI at ModelScope Notebook

课程 Notebook、图片、数据辅助文件位于 `tutorials/`；静态预览位于 `html/`。

从仓库根目录运行 `python build_html.py` 可重新生成预览，不执行训练。打开 `html/index.html` 即可浏览全部课程。

PPT、环境清单和验证报告仅保留在 [GitHub](https://github.com/VoyagerXvoyagerx/nvidia-dli-deep-learning-zh-modelscope)。ModelScope 镜像已预装课程所需库，直接运行 Notebook 即可。
